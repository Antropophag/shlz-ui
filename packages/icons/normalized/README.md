# Normalized Figma basic icons

Generated by `node tools/normalize-basic-icons.mjs` from the read-only Figma export. Repository policy forbids writing under `shlz-design-source/`, so the requested normalized catalog lives here instead. This Basic Elements base is extended by `normalize-icons-sheet.mjs` before `@shlz/icons` generation.

## Inventory

- 133 source SVG files become 119 logical glyphs and 125 emitted SVG variants.
- Source dimensions: 100 × 24×24, 21 × 40×40, 6 × 20×20, 5 × 24×25 and 1 × 16×16.
- All 21 40×40 files are semantic file-type glyphs; this export contains no 40×40 interface container around a smaller glyph.
- 101 source files use one paint; 32 are multicolor. Twenty-five carry intentional semantic colors.

## Rules

- Geometry, viewBox and path data are preserved; no SVG optimizer is used.
- Ordinary monochrome glyph paints become `currentColor`.
- File-type and priority colors are preserved as semantic source colors. The interface source named `File type icon` is classified the same way from its multicolor file-badge geometry.
- Default/Hover sources are collapsed only when geometry is identical; CSS owns color-only states.
- Arrow state sources emit Default geometry with `currentColor`; their authored container background/opacity is a CSS state concern. Delete containers use `currentColor` for the glyph while retaining the independent source border paint.
- Source-authored size variants remain separate files under one logical manifest icon.
- Exact geometry duplicates are represented by one logical icon with all source paths retained.
- Ambiguous names keep conservative `-uncertain` or `-alt` qualifiers pending manual review.

## Collapsed sources

- Arrow Closed/Open: Default and Hover collapse per 20/24 size because geometry is identical.
- Delete contained: Default and Hover collapse per 20/24 size because only glyph paint changes.
- Drag & drop Default/Hover and the exact duplicate `intarface/Menu.svg` become `six-dot-grid`; the purpose remains ambiguous.
- PDF/PDF Gray become two semantic color variants of `file-pdf`.
- High/Medium/Low priority become three semantic color variants of one `priority` geometry.

## Categories

Normalized files are grouped into `actions`, `navigation`, `interface`, `status`, `sidebar`, `editor` and `files`. The Figma folder typo `intarface` is corrected only in normalized paths; source paths remain literal.

## Traceability

`manifest.json` maps every logical icon and emitted variant to all contributing source paths. `analysis.json` records width, height, viewBox, fills, strokes, colors, element counts, source SHA-256, geometry SHA-256, state and container classification for every one of the 133 raw files.

## Manual review required

The following source names do not establish a reliable purpose: `flagq-uncertain`, `icon-20-uncertain`, `icon-32-uncertain`, `icon-wrapper-16-uncertain`, `icon-wrapper-24-uncertain`. The `-alt` variants are retained because their geometry differs; their more specific semantics are UNKNOWN. `nearDuplicateGroup` is a review hint, never an automatic merge rule.

## Icons.svg sheet extension

The second normalization stage reads all 125 recovered candidates from the authoritative `raw/svg/Icons.svg` sheet. Historical extraction metadata supplies grouping and crop localization only; every emitted primitive is matched back to the raw SVG byte geometry before use.

- All 406 raw path/rect primitives are frozen in an independent partition: 302 candidate primitives and 104 non-icon sheet chrome/label primitives.
- Exact deduplication requires matching topology, viewBox, paint policy, and ordered element-level paint assignments. No sheet candidate passes every check; 62 add a new canonical name and 63 name/geometry collisions receive an explicit qualified name.
- `calendar-sidebar` and `calendar-interface` preserve the two distinct candidates that previously collided as `calendar.svg`.
- The merged production input contains 244 canonical logical icons and 250 emitted variants.
- `icons-sheet-analysis.json` records source IDs, category, crop transform, source paints, semantic-name confidence, topology hash, and disposition for every candidate.
