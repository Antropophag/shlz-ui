## Why

Wave 10 established a verified source-only boundary for Card with button, Reports card, and Cover, but consumers still have no framework-neutral production compositions for those source-backed layouts. This change supplies deliberately narrow presentational contracts without promoting the static exports into an unsupported generic Card, navigation, media, or application-data API.

## What Changes

- Add three CSS/HTML composition contracts: Card with action, Report card, and Cover.
- Preserve source-backed fixed specimens while providing bounded fluid variants for structured consumer content and narrow containers.
- Compose existing Button and Link primitives for actions; keep activation, navigation, loading, data, and media lifecycle consumer-owned.
- Add Showcase fixtures and one real Data Workspace consumer, documentation, component manifests, occurrence guards, and source/runtime/accessibility/visual/responsive evidence for each independent composition.
- Replace the Wave 10 source-only absence disposition with independent implemented statuses without modifying `shlz-design-source/`.
- Exclude a generic `.shlz-card` API, whole-surface click behavior, JavaScript controllers, framework adapters, application models, asynchronous states, and invented design tokens.

## Capabilities

### New Capabilities

- `application-compositions/card-with-action`: Presentational content, illustration, and nested-action composition based on `Card with button.svg`.
- `application-compositions/report-card`: Presentational report-summary surface variants based on `Reports card.svg`.
- `application-compositions/cover`: Static structured cover composition based on `Cover.svg`.

## Impact

The public `@shlz/styles` stylesheet gains new class contracts and documentation. Showcase and Data Workspace gain classified executable occurrences. Audit manifests, project inventory, focused tests, browser evidence, and the Wave 10 report change from a source-only absence disposition to implementation-specific evidence. No behavior package, dependency, framework adapter, source asset, or existing selector changes.
