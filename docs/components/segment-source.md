# Segment source contract

`Segmented-Group` (`424:36756`) has six Size × Icon variants. Heights are
26/33/41 for small/medium/large; widths are 319/377 without icons and 419/477
with icons depending on size. `Segmented-Item` (`424:36728`) has nine observed
Selected × Disabled × Size combinations at 18/25/33px. There is no
selected+disabled source variant.

The group uses a 4px shell inset and content/composition-driven item widths.
Production native radios preserve single-selection behavior. Icon slots use
normalized image assets rather than text glyphs.
