# Calendar Grid

Calendar Grid is a framework-neutral native-table composition for row-by-date operational data. It works in plain HTML, server-rendered PHP, Vue templates, and other renderers without a JavaScript rendering runtime.

Consumers own row, date, and item identities; ordering; locale and timezone formatting; temporal and unavailable classification; loading, errors, permissions, filtering, selection, persistence, rerendering, and item actions. The library owns presentation, contained scrolling, sticky context, and optional disclosure synchronization.

Wrap an accessible `table` in `.shlz-calendar-grid`, label every row and date with native `th` elements, and connect data cells with `headers`. The first required header row contains one native `<th scope="colgroup" colspan="…">` for each contiguous `past`, `today`, and `future` group; its span must exactly match that group's date columns. The next row contains separate `<th scope="col">` date headers. Temporal names belong only to the group row—not to date secondary labels or date accessible names. An optional consumer-owned month or period row may add context, but cannot replace the temporal row.

Set `data-shlz-calendar-grid-state="past|today|future"` on each temporal group, date header, and corresponding body cell. The group headers receive the source inner treatments: trailing-rounded muted Past, fully rounded accent Today over a subtle outer surface, and leading-rounded muted Future. The Today date header and whole body column retain the subtle source fill; Past and Future body cells retain the base surface. Mark unavailable dates independently with `data-shlz-calendar-grid-unavailable="<reason>"` while retaining their temporal state. This composes the source hatch across affected date/body cells without moving them out of Past, Today, or Future, and visible or assistive text must explain the reason. The library paints consumer-authored states but does not calculate them. Generic item tones are presentation-only: `accent`, `success`, `warning`, and `danger` carry no business meaning.

Optional disclosure uses a native button with `data-shlz-calendar-grid-disclosure="row|cell"`, globally unique `aria-controls`, and `aria-expanded`. Call `enhanceCalendarGrids()` or construct `CalendarGridController`. The controller emits bubbling `shlz:calendar-grid-disclosure` events with `{ kind, id, expanded }`, is idempotently enhanced, and can be destroyed before consumer rerendering.

The grid is bounded and non-virtualized. Override `--shlz-calendar-grid-row-header-width`, `--shlz-calendar-grid-column-width`, and `--shlz-calendar-grid-max-block-size` at the composition seam when necessary.
