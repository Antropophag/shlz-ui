Primary authority is `shlz-design-source/raw/svg/Calendar.svg` (SHA-256 `da5c97cd453930458634ec3317452dced33b8de41c418d744bf253ed75af8714`). It remains unchanged.

They supplement but never override the raw repository SVG.

- Source facts: dense row/date matrix, restrained `#D1D8DF` separators, compact item surfaces, count indicators, muted/unavailable dates, and expanded/collapsed examples. `Calendar Cell` exposes `Time` and `Date` as distinct header primitives: `ПРОШЛОЕ`, `СЕГОДНЯ`, and `БУДУЩЕЕ` occupy the standalone Time treatment, while the Date treatment separately contains the numeric date and weekday. The Time variants use white outer cells for past/future and a `#F4F6F9` outer cell for today. Their inner 32px surfaces are: past `#EEF0F4`, inset 1px at the start and 4px elsewhere with trailing 8px corners; today `#3D88DE`/15%, inset 4px and rounded 8px on every corner with `#253D98` text; future `#EEF0F4`, inset 4px at the start/block edges, flush at the end, and rounded 8px at the leading corners. All retain `#D1D8DF` separators and past/future use dark text. The Date variants retain compact bordered surfaces. The Calendar Cell variants render every demonstrated Today body-cell size/content state with `#F4F6F9`; Day off uses a white base with repeated `#F5F5F5` diagonal hatch and ordinary separators; Day off / Today demonstrates the two states can coexist. The authority contains no separate past or future body-cell paint. A month-labelled Time variant is present, but the SVG does not establish a month band as a substitute for the temporal-state row.
- Supplemental evidence: full-screen operational compositions show sticky-looking date/row context and two-axis scrolling.
- Derived patterns: today body fill applies to the whole today column because the source repeats it across empty, count, short-list, long-list, and collapsed body variants; unavailable hatching fills the affected cell surface without replacing temporal membership.
- Repository decisions: native table semantics express each contiguous Time treatment as `scope="colgroup"` with consumer-authored exact `colspan`; the five-date Showcase chronology produces Past/Today/Future spans `1/1/3`, with its weekend and holiday columns remaining Future. The separate Date row uses `scope="col"`; optional month/period grouping is an additional consumer-owned row. Other decisions are contained native scrolling, temporal attributes retained on date/body cells for paint, a separate unavailable attribute, generated inner group surfaces, role-specific selectors mapped to existing source tokens, generic tone names, and one disclosure controller. Past and future body cells intentionally retain the base surface instead of receiving invented paint.
- Assumptions: sticky behavior is inferred from the supplied operational layouts and degrades to table flow; the component is bounded and non-virtualized. The source does not define consumer period-row sticky offsets, so an added month/period row owns its matching corner span and offset customization. No visual-state assumption is needed for the supported temporal states.
- Unsupported: date calculation, locale/timezone policy, work-calendar inference, fetching, filtering, selection, persistence, virtualization, drag/drop, and application actions.

The supplied screens' identity, profile, tabs, filters, statistics, statuses, and routing are application evidence only and are excluded from the module interface.
