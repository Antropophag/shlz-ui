# Component taxonomy

Static SVGs establish rendered geometry and represented visual rows, not behavior contracts. “Observed states” below means visual examples; hover/focus semantics remain UNKNOWN unless validated later. Accessibility requirements are repository requirements (DECISION), not Figma facts.

| Family                          | Purpose and confirmed evidence                                          | Observed variants/states                                         | Dependencies                           | Behavior / accessibility                                                          | Layer                                   |
| ------------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------- |
| Button                          | Actions; 26, 32, 40 px heights, pill radii                              | text/icon-only; blue, neutral, disabled-looking state rows       | action colors, icons, control geometry | native button; keyboard activation, accessible name                               | CSS-only primitive                      |
| Checkbox                        | Binary selection; 16/20 px frames                                       | checked, unchecked, indeterminate-looking, disabled-looking rows | borders, action color, check icon      | native input, label, mixed state contract UNKNOWN                                 | CSS-only                                |
| Radio                           | Exclusive selection; 18.5 px observed marker                            | selected/unselected and disabled-looking                         | borders, action color                  | native grouped radios, label, keyboard navigation                                 | CSS-only                                |
| Switch                          | Binary immediate setting; 24×14 and 38×20                               | on/off and disabled-looking rows                                 | action/neutral colors                  | native checkbox with switch role; application owns persistence                    | CSS-only                                |
| Input / Number / Textarea       | Text entry; pill 32/40 px input, textarea about 395×58 with 8 px radius | default, populated, error/success/disabled-looking examples      | control, border, status, icons         | native controls, labels, errors; number stepping details UNKNOWN                  | CSS-only + vanilla behavior             |
| Select                          | Choice input; 250/280 widths shown, 32/40 px heights                    | closed/open-looking sheets, tags, validation-looking states      | control, dropdown, icons, tags         | native select where possible; custom keyboard/typeahead contract UNKNOWN          | Web Component candidate                 |
| Status / Badge / Tag            | Compact metadata; status 30 px, tags ~30 px; badge geometries vary      | multiple colors, icon/count/avatar forms                         | status colors, icons                   | text must carry meaning beyond color; removal control when interactive            | CSS-only; Tag implemented               |
| Tabs / Segment                  | View switching; tabs around 40 px; segments 18/25/33 px examples        | underline/pill/boxed; three Segment sizes                        | action/neutral colors                  | ARIA tabs with automatic activation; Segment uses native radio choice             | Tabs vanilla behavior; Segment CSS-only |
| Pagination                      | Navigate result pages; 39/40 px round items                             | current/other, arrows, compact examples                          | links, icons                           | native links; current page and labels; disabled controls are non-links            | CSS-only; implemented                   |
| Tooltip                         | Supplementary label; 100×37 and 8 px radius examples                    | four sides; start/center/end shown vertically                    | shared floating geometry               | `role=tooltip`, `aria-describedby`, hover/focus/Escape; non-interactive           | vanilla behavior; implemented           |
| Popover                         | Floating supplementary content; 236×90, radius 12, arrow on four sides  | top/bottom/left/right with three arrow alignments                | surface, shadow, positioning engine    | native button trigger; Escape/outside dismissal; no role or focus trap by default | vanilla behavior implemented            |
| Dropdown menu                   | Contextual command menu; 200/216 px, 40 px rows, radius 12              | highlighted and disabled-looking rows                            | surface, shadow, icons                 | composite menu keyboard navigation and dismissal implemented                      | vanilla behavior implemented            |
| Modal                           | Blocking dialog; examples 416×165 and 572×196 radius 16                 | structured and compact content/action layouts                    | surface, native dialog, buttons        | native modal semantics/focus/Escape; opt-in backdrop dismissal                    | vanilla behavior over `<dialog>`        |
| Drawer                          | Modal edge panel; 420×900 source surface, 64/764/72 regions             | right placement implemented; other placements unsupported        | native dialog lifecycle, buttons       | native modal semantics; scrollable body; non-modal contract UNKNOWN               | vanilla behavior over `<dialog>`        |
| Notification                    | Feedback; toast-like rows 384×58 radius 29                              | dark/red/light, action/close examples                            | status, icons, buttons                 | consumer selects status/alert; lifecycle, timeout and stacking remain UNKNOWN     | CSS-only visual primitive; implemented  |
| Table / Table Cell              | Structured data; repeated 50 px rows, many 30 px chips/controls         | header/body, sorting/selection/action examples                   | checkbox, status, icons, controls      | semantic table, sortable headers, captions; virtualization UNKNOWN                | CSS-only structure + adapter            |
| Date Picker / Calendar          | Date entry; input 32/40 px; overlay examples 280×234 / 256×210          | single-date visuals and navigation states                        | input, popover, buttons, icons         | grid keyboard model, locale/range/timezone UNKNOWN                                | Web Component candidate                 |
| Avatar                          | Identity; 24/32/40/64 px circles                                        | image, initials/placeholder-like rows                            | surfaces, embedded image               | meaningful alt or decorative contract                                             | CSS-only                                |
| Header / Sidebar                | Global shell navigation; sidebar 72 px rail and 300 px panel examples   | expanded/collapsed-looking visuals                               | navigation, icons, avatar              | landmarks and navigation; app routing                                             | application pattern                     |
| Card with button / Reports card | Domain content grouping; 314×230 radius 16                              | image/content/actions                                            | surface, buttons, images               | heading hierarchy and action semantics                                            | application pattern                     |

Additional sheets (Link, Card, Calendar and screen exports) are evidence inputs, not proof that every composition belongs in the reusable core. Complex table, date-picker, select and application layouts remain deferred.

Implemented contracts are recorded individually in `docs/components/`. CSS-only primitives remain native HTML; Dropdown, Popover, Tooltip, Tabs, Modal and Drawer add small opt-in controllers without a framework or component runtime.
