# SHLZ Design Source

Exhaustive formalization pass over the supplied Figma SVG exports. This package is **source knowledge**, not a framework-specific UI library.

Start with `reports/extraction-report.md` and `source-map/summary.json`.

Directories:
- `inventory/` source files and checksums
- `tokens/` observed visual primitives
- `geometry/` dimension frequency data
- `components/` component-sheet fingerprints
- `layouts/` screen-level geometry
- `duplicates/` exact duplicate/vector evidence
- `assets/` extracted raster payloads and previously isolated vector icons
- `source-map/` extraction coverage/limitations
